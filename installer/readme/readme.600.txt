PRS+ installation for Sony PRS-600

Warning: make sure your reader is charged before starting.

The original PRS-600 base-image preparation is required only for readers
that have never been prepared for PRS+. If a PRS+ base image is already
installed, skip directly to the update steps.

To install an update:

1) Copy the complete `PRSPInstaller` folder from this archive to the root of
   the reader's internal storage.
2) Safely eject the reader and restart it.
3) The installer runs automatically during startup. There is no PC installer
   window.
4) Wait for the reader to finish restarting, then remove `PRSPInstaller` if it
   is still present.

Installation details are written to `Data/PRSPInstaller/install.log`.
